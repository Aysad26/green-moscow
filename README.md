# Зелёные острова Москвы — версии проекта

Четыре самостоятельные концепции. Снимок исходников от 16 октября 2026 года.

| Папка | Версия |
|---|---|
| atlas | Фотоколлажная |
| engraving | Гравюрная |
| watercolor | Акварельная |
| wooden | Деревянный город, Three.js |

В каждой папке сохранены исходники и готовая статическая сборка `dist`. Для просмотра запустите `python3 -m http.server 8000` внутри соответствующей папки `dist` и откройте http://localhost:8000. Дополнительные инструкции находятся в README каждой версии.

Карта и анкета имеют демонстрационный характер; для рабочего запуска требуется подключение сервисов и серверной обработки.
