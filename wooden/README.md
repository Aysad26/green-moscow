# Зелёные острова Москвы — деревянный атлас

Полный лендинг в стиле деревянного конструктора. Структура и работающие элементы перенесены из акварельной версии: об акции, участие, карта с фильтрами, приглашение и контакты.

- Модель из кубиков, пирамид, конусов, цилиндров и арок; 65 анимируемых модулей.
- Увеличенный городок опущен к нижней границе первого экрана.
- Реальная 3D-сборка длительностью 4,52 секунды, повтор по кнопкам.
- Поворот перетаскиванием; стрелки влево/вправо и Home при фокусе на сцене.
- Приглушённая палитра, процедурная текстура дерева, скруглённые кромки, мягкие тени.
- Golos Text, кириллица включена; лицензия OFL в assets/golos-OFL.txt.
- Новые статичные иллюстрации: ВДНХ, Царицыно, Коломенское, Сокольники. Созданы встроенной генерацией изображений по референсу деревянной 3D-сцены, прозрачность сохранена.
- Шейпы между словами бегущей строки и отдельная кнопка паузы.
- При prefers-reduced-motion сцена сразу собрана, строка не движется.
- Все зависимости и шрифты локальные. Внешние CDN и API не используются.
- Без WebGL показывается проекция той же модели, данные никуда не отправляются.

Развёртывается каталог dist без сборки. Проверки: `node scripts/verify.mjs`, `node scripts/verify-ui.mjs`.

Проверяются состояния сборки, конечные координаты, геометрия, 18 сочетаний соотношения сторон и поворота, наличие файлов и локальные импорты. DOM-проверки покрывают поиск, фильтры, вкладки, масштаб, анкету, безопасный вывод текста, диалоги и паузу на desktop/mobile. Живая браузерная проверка в окружении создания недоступна.

Анкета показывает локальный предпросмотр. Рассказы, счётчики и точки карты демонстрационные; серверная отправка и модерация не подключены.

Иллюстрации: `dist/assets/wood/`. Общая часть промптов: static raster illustration for Green Moscow, same minimalist wooden toy construction vocabulary, large cubes / rectangular blocks / arches / cones / cylinders, softly beveled matte painted wood, subtle grain, muted sage / forest green / terracotta / warm cream / dusty blue / ochre, three-quarter isometric camera, soft warm studio light, transparent alpha, no text or watermark. Отдельные сюжеты: ВДНХ с аркой и Центральным павильоном; красно-белый дворец и мост Царицыно; шатровая церковь Вознесения и парк Коломенского; арка, пруд и роща Сокольников.
